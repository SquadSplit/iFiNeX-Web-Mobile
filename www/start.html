How do you want to use iFiNeX?

Pick one. You can change it later in the menu (☰ → Connection) — your data is never deleted by switching.

☁️ Connect to a server

Shared bills, squad, delegates and e-mail-code login. You need the web address of your group’s server (the one your admin gave you).

📱 Standalone — this phone only

Everything stays on this phone. No account, no login, no internet needed. Back up to a file any time (and optionally to your Google Drive).

Servers only receive what you type into the app. Nothing is sent to anyone when you choose Standalone.
